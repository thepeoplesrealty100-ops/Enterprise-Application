**3. Responsive Design Breakpoints**

```
Mobile (< 768px):
  - Single column layout
  - Full-width cards (100%)
  - Collapsible navigation
  - Vertical stacking of graphs/maps

Tablet (768px - 1024px):
  - 2-column grid
  - 50% width cards
  - Sidebar toggleable
  - Maps smaller, graphs adapt

Desktop (1024px - 1440px):
  - 3-column grid
  - Fixed sidebar (240px)
  - 33% width primary cards

Large (> 1440px):
  - 4-column grid
  - Fixed sidebar (280px)
  - 25% width primary cards
  - Additional panels visible
```

**4. Form-Fitted Design Principles**

```css
/* NO WASTED SPACE APPROACH */

.module-container {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(300px, 1fr));
  gap: 8px;  /* Minimal gap */
  height: 100%;  /* Use full available height */
}

.graph-container {
  aspect-ratio: 16 / 9;  /* Fixed ratio, prevents layout shift */
  overflow: hidden;  /* No scrollbars inside cards */
  position: relative;
}

.graph {
  width: 100%;
  height: 100%;
  display: flex;
  flex-direction: column;
}

/* Dynamic sizing - no fixed heights */
.chart {
  flex: 1;
  min-height: 0;  /* Critical for flex children */
  resize: both;  /* User can adjust if needed */
}

/* Map fitting */
.map-container {
  width: 100%;
  height: 100%;
  position: relative;
}

/* Table scrolling inside container, not page */
.table-wrapper {
  width: 100%;
  height: 100%;
  overflow: auto;  /* Scroll inside, not page scroll */
  border: 1px solid #333;
}
```

## PART 9: NEW DATABASE SCHEMA

```sql
-- Nanoswarm Management
CREATE TABLE nanoswarms (
  id UUID PRIMARY KEY,
  name TEXT NOT NULL,
  type TEXT,  -- 'remediation', 'surveillance', 'data-collection'
  swarm_size INT,
  sensor_triggers JSONB,  -- Which sensors trigger deployment
  status TEXT,  -- 'idle', 'deploying', 'active', 'returning', 'dormant'
  last_deployment TIMESTAMP,
  created_at TIMESTAMP
);

-- Sensor Integration
CREATE TABLE sensors (
  id UUID PRIMARY KEY,
  name TEXT NOT NULL,
  type TEXT,  -- 'chemical', 'thermal', 'acoustic', 'visual', etc.
  location JSONB,  -- GPS coordinates
  last_reading JSONB,
  threshold_rules JSONB,  -- When to trigger response
  nanoswarm_id UUID REFERENCES nanoswarms(id),
  last_reading_time TIMESTAMP
);
```
