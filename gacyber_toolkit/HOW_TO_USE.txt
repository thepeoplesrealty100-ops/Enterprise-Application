QUICK START (Windows/WSL)
─────────────────────────
  python3 toolkit.py          # Interactive Python launcher
  bash toolkit.sh             # Bash launcher (Kali/WSL)
  bash environment.sh         # Verify all components are present

SETTING UP PYTHON
─────────────────
  pip install -r requirements.txt
  # Python 3.12+ recommended (tested with 3.12.9)

TOOLS NEEDED IN PATH
────────────────────
  nmap            → https://nmap.org/download
  whois           → apt install whois  /  winget install whois
  gobuster        → apt install gobuster  /  go install
  nikto           → apt install nikto
  sqlmap          → apt install sqlmap  /  pip install sqlmap
  hydra           → apt install hydra
  aircrack-ng     → apt install aircrack-ng (Kali)
  theHarvester    → pip install theHarvester
  shodan CLI      → pip install shodan && shodan init <API_KEY>
  dnsrecon        → pip install dnsrecon

ENGAGEMENT WORKFLOW
───────────────────
  1. Get signed Rules of Engagement / Statement of Work
  2. Fill Resources/Targets/targets.txt and scopes.txt
  3. python3 toolkit.py  → follow phase menu
  4. All output auto-saves under ~/Documents/Pentest_Projects/<date>_<target>/
  5. Run "08 Generate Report Template" when complete
