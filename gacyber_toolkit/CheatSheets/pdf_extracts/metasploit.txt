Metasploit
Source: https://www.metasploit.com
Metasploit is an open-source project that provides the infrastructure, content, and tools to
perform penetration tests and extensive security auditing. It is a tool that provides information
about security vulnerabilities and aids in penetration testing. Metasploit framework is also used
for developing and executing exploits which promotes in gaining remote access to a system by
exploiting any vulnerability present in that server. Meterpreter is a payload inside the
framework.
