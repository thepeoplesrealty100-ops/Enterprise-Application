RustScan
Source: https://docs.rs
RustScan is a modern port scanner written in the Rust programming language, designed to be
both fast and efficient. It is especially noted for its speed, simplicity, and ability to integrate with
other tools like Nmap.
The following tables list the various options and commands associated with RustScan.
Syntax
rustscan [FLAGS] [OPTIONS] <ip> [command]...
Options
-a Used to specify the target IP address or URL
-r, --range Used to specify the range of ports to scan
-T, --timeout The timeout before a port is assumed to be close
-b, --batch Increases speed of scanning
