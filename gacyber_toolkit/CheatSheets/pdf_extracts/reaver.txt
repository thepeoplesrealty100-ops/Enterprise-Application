Reaver
Source: https://github.com
Reaver has been designed to be robust and can perform practical attacks against Wi-Fi Protected
Setup (WPS) registrar PINs to recover WPA/WPA2 passphrases. It can also brute force the WPA
handshaking process remotely, even though the physical button has not been pressed on the
access point.
Syntax
reaver [OPTIONS]
Download, Compile and Install
git clone https://github.com/t6x/reaver-wps-fork-t6x
or
wget https://github.com/t6x/reaver-wps-fork-t6x/archive/master.zip &&
unzip master.zip
./configure
make
sudo make install

-i, --interface=<wlan> Name of the monitor-mode interface to use
-b, --bssid=<mac> BSSID of the target AP
-m, --mac=<mac> MAC of the host system
