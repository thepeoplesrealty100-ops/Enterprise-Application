WPScan Cheat Sheet
WPScan
Source: https://github.com
WPScan is a powerful tool used by attackers to identify vulnerabilities in WordPress websites. It
automates the process of discovering security issues, outdated components, and potential entry
points that can be exploited.
Syntax
wpscan --url <URL> --enumerate p
Options
The URL of the blog to scan. Allowed Protocols: http, https. Default
--url URL Protocol if none provided: http. This option is mandatory unless update
or help or hh or version is/are supplied.
-h, --help Display the simple help and exit.
--hh Display the full help and exit.
--version Display the version and exit.
-v, --verbose Verbose mode.
--[no-]banner Whether or not to display the banner. Default: true.
-o, --output FILE Output to FILE.
-f, --format Output results in the format supplied. Available choices: cli-no-color,
FORMAT json, cli, cli-no-colour.
--detection-mode
Default: mixed. Available choices: mixed, passive, aggressive.
MODE
--user-agent, --ua
Specify a custom user-agent.
VALUE

-e, --enumerate

--exclude-content- Exclude all responses matching the Regexp (case insensitive) during parts
based of the enumeration. Both the headers and body are checked. Regexp
REGEXP_OR_STRING delimiters are not required.

Example Commands
Command Description
Performs a basic scan of the specified WordPress
wpscan --url http://example.com
site.
wpscan --url http://example.com - Enumerates all installed plugins on the specified
-enumerate p site and checks for known vulnerabilities.
wpscan --url http://example.com - Enumerates all installed themes on the specified
-enumerate t site and checks for known vulnerabilities.
wpscan --url http://example.com -
Enumerates all users on the specified site.
-enumerate u
wpscan --url http://example.com - Performs a brute-force attack using the specified
-passwords /path/to/passwords.txt password list.
wpscan --url http://example.com - Uses the WPScan API to get the latest vulnerability
-api-token YOUR_API_TOKEN data.
wpscan --url http://example.com - Uses a random user-agent for the scan to avoid
-random-user-agent detection.
