Gobuster Cheat Sheet
Gobuster
Source: https://github.com
Gobuster is a Go programming-based directory scanner that allows attackers to perform fast-
paced enumeration of hidden files and directories of an application. It is a convenient command-
oriented tool used to brute-force URIs in websites, DNS subdomains, names of the virtual hosts
on the target server, etc.
The following table lists the various Gobuster commands and their respective operations:
1. <dns> Mode Options
2. <dir> Mode Options
3. <vhost> Mode Options
4. <dns> Mode Commands
5. <dir> Mode Commands
6. <vhost> Mode Commands

4. <dns> Mode Commands
Command Description
gobuster dns -d <Target Website> Set number of threads to brute-force
-t 50 -w common-names.txt directories or subdomain names
gobuster dns -d <Target website>
Display all the sub-domains
-w ~/wordlists/subdomains.txt
gobuster dns -d <Target website> Display IP addresses of the obtained
-w ~/wordlists/subdomains.txt -i subdomains
