ShellGPT
Source: https://github.com
ShellGPT is a command-line productivity tool powered by AI large language models (LLM) that
offers streamlined generation of shell commands, code snippets, documentation, eliminating the
need for external resources (like Google search). ShellGPT is designed to quickly analyze and
retrieve information for straightforward requests ranging from technical configurations to
general knowledge.
Syntax
Prompt [PROMPT] The prompt to generate completions for.
Options
--help Show options
--model <TEXT> Large language model to use. [default: gpt-4o]
--temperature <FLOAT RANGE
Randomness of generated output. [default: 0.0]
[0.0<=x<=2.0]>
--top-p < FLOAT RANGE
Limits highest probable tokens (words). [default: 1.0]
[0.0<=x<=1.0]>
--md or --no-md Prettify markdown output. [default: md]
--editor Open $EDITOR to provide a prompt. [default: no-editor]
--cache Cache completion results. [default: cache]
--version
Show version
Assistance Options
--shell or -s Generate and execute shell commands
