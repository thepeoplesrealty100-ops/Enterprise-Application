CloudFox
Source: https://github.com
CloudFox helps in gaining situational awareness in unfamiliar cloud environments. It is a
command-line tool designed to find exploitable attack paths in cloud infrastructure. It automates
the process of discovering cloud assets such as storage buckets, virtual instances, databases, and
other services, making it easier to uncover potential security vulnerabilities and
misconfigurations. CloudFox supports multiple cloud environments, including AWS, and Azure,
allowing users to perform thorough scans and generate detailed reports on their cloud
infrastructure.
Syntax
cloudfox aws --profile [profile-name] all-checks
Options
-p, --profile Specify the AWS profile to use.
-v, --verbosity Set the level of verbosity for output (e.g., -v2).
--tenant Specify the Azure tenant ID.
--subscription Specify the Azure subscription ID.
--organization Specify the AWS organization to enumerate.
--resource-group Specify the Azure resource group.
--region Specify the AWS region.
--output Specify the output format (e.g., JSON, CSV).
--config Provide a custom configuration file.
Note: Some options are specific to AWS and others to Azure.
