Nbtstat
Source: https://www.microsoft.com
Nbtstat displays NetBIOS over TCP/IP (NetBT) protocol statistics, NetBIOS name tables for both
the local computer and remote computers, and the NetBIOS name cache. Nbtstat allows a refresh
of the NetBIOS name cache and the names registered with Windows Internet Name Service
(WINS). Used without parameters, nbtstat displays help.
Syntax
nbtstat [/a <remotename>] [/A <IPaddress>] [/c] [/n] [/r] [/R] [/RR]
[/s] [/S] [<interval>]
