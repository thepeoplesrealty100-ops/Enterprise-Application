Nikto
Source: https://cirt.net
Nikto is an Open Source (GPL) web server vulnerability scanner that can perform wide-ranging
tests against web servers of over 6700 potentially dangerous files/CGIs and can check for any
older versions of over 1250 servers, and version specific problems on over 270 servers. It also
checks for server configuration items, HTTP server options, captures, and prints any cookies
received and tries to identify any newly installed web servers and software.
