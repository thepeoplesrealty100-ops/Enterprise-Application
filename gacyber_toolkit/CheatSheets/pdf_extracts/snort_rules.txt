Snort Rules Cheat Sheet
Snort
Source: https://www.snort.org
Snort is an open-source network intrusion detection system, that can perform real-time traffic
analysis and packet logging on IP networks. Snort's rule engine enables custom rules to meet the
needs of the network. Snort rules help in differentiating between normal internet activities and
malicious activities.

Options Description

-e Display link-layer headers
-d Display packet data payload
