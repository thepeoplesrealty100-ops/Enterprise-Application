Mole
Source: https://sourceforge.net
It is a command-line interface SQL Injection exploitation tool. It can detect the injection on the
site and exploit it, only if a vulnerable URL and a valid string are provided. Mole can be used to
exploit both union-based and blind Boolean-based injections and supports MySQL, SQL Server,
and Oracle databases.
Syntax
./mole.py [PARAMS]
Options
-u <URL> URL that contains an SQLi vulnerability
-n <NEEDLE> String printed on good queries
THREADS: The number of threads to run.
-t <n>
Default is 4
-p <PARAM> Sets the GET vulnerable param
