Sn1per
Source: https://github.com
Sn1per is an automated scanner that can be used to enumerate and scan for vulnerabilities. It
automates the process of reconnaissance, scanning, and reporting on target hosts and networks.
It combines multiple tools and techniques to gather information and identify vulnerabilities.
Syntax
sniper [options] -t <target>
Options
-t Target URL or IP address
-m Mode to run (e.g., passive, active, full)
-w Enable web module
-r Enable reporting
-f Enable full scan
-n Enable non-intrusive mode
-o Output directory
-q Quiet mode
-v Verbose mode
-h Display help message
--dns Enable DNS enumeration
--osint Enable OSINT collection
--recon Enable reconnaissance
