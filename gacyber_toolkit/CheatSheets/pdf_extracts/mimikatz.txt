Mimikatz
Source: https://github.com
Mimikatz is an open-source application that allows users to view and save authentication
credentials. Attackers make use of this tool to extract plaintexts passwords, hash, PIN code, and
Kerberos tickets from memory.
The following table lists the various Mimikatz modules and their respective description
