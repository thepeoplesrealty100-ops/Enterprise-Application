hping3 Cheat Sheet
hping3
Source: http://hping.org
hping is a command-line oriented TCP/IP packet assembler/analyzer for the TCP/IP protocol that
sends ICMP echo requests and supports TCP, UDP, ICMP, and raw-IP protocols.
Syntax
hping3 [options] <Target>
The following table lists the various Hping commands and their respective scanning methods.

1. Scan Commands
hping Command Description
hping3 -q <Target> (or)
Scans quietly
hping3 --quiet <Target>
hping3 -I <Target> (or)
Interface name (to be used for sending packets)
hping3 --interface <Target>
hping3 -D <Target> (or)
Debugging info
hping3 --debug <Target>
hping3 -c <Target> (or)
Packet count (to be sent)
hping3 --count <Target>
hping3 -V <Target> (or) Enable verbose output
hping3 --verbose <Target> Example: hping3 -V -S <target ip>
hping3 -i <Target> (or) Wait (uX for X microseconds, for example -i
hping3 --interval <Target> u1000)
hping3 -v <Target> (or) Show version information and API used to access
hping3 -- version <Target> to data link layer, linux sock packet or libpcap
hping3 -n <Target> (or)
Numeric output
hping3 --numeric <Target>
hping3 -z <Target> (or)
Used to bind. Use ctrl+z to increment TTL
hping3 --bind <Target>
hping3 -Z <Target> (or)
Used to unbind
hping3 --unbind <Target>
hping3 --beep <Target> Beep for every matching packet received
Sent packets as fast as possible. Don't show
hping3 --flood <Target>
replies
hping3 --fast <Target> Sends 10 packets / sec
hping3 --faster <Target> Sends 1 packet / µs

2. IP Related Commands
hping Command Description
hping3 -a <Target> (or)
Spoof source address
hping3 --spoof <Target>
hping3 -A <Target> -p 80 ACK scanning on port 80
Random destination address mode
hping3 --rand-dest <Target>
Example: hping3 -1 10.0.1.x --rand-dest –I eth0
hping3 --rand-source
Random source address mode
<Target>
hping3 -t <Target> (or)
Set TTL (time to live) value
hping3 --ttl <Target>
hping3 -N <Target> (or)
id [default random]
hping3 --id <Target>

hping3 -W <Target> (or)
Use win* id byte ordering
hping3 --winid <Target>
hping3 -r <Target> (or)
Relativize id field to estimate host traffic
hping3 --rel <Target>

Split packets in more fragments

Set fragment offset value

hping3 -G <Target> (or) Includes RECORD_ROUTE option and display the
hping3 --rroute <Target> route buffer
set virtual MTU, implies --frag if packet size >MTU
hping3 -m <Target> (or)
hping3 --mtu <Target>

5. ICMP Related Commands
hping Command Description
hping3 -C <Target> (or) Set icmp type, default is ICMP echo request
hping3 --icmptype <Target> (implies --icmp).
hping3 -K <Target> (or)
Set icmp code, default is 0 (implies --icmp)
hping3 --icmpcode <Target>
Set IP version of IP header contained into ICMP
hping3 --icmp-ipver <Target>
data, default is 4
hping3 --icmp-iphlen Set IP header length of IP header contained into
<Target> ICMP data, default is 5 (5 words of 32 bits)
hping3 --icmp-iplen ip Set IP packet length of IP header contained into
<Target> ICMP data, default is the real length
Set IP id of IP header contained into ICMP data,
hping3 --icmp-ipid <Target>
default is random
hping3 --icmp-ipproto Set IP protocol of IP header contained into ICMP
<Target> data, default is TCP.
