💻 TECHNICAL REFERENCE QUICK COMMANDS
═══════════════════════════════════════════════════════════════════════════════

DOCKER COMMANDS:
  docker compose up -d --build      # Start all containers
  docker compose ps                  # Check status
  docker compose logs -f backend     # View live logs
  docker compose down                # Stop everything
  docker compose exec backend bash   # Access container shell

KUBERNETES COMMANDS:
  kubectl create namespace jakal                           # Create namespace
  kubectl apply -f k8s/jakal-backend-complete.yaml        # Deploy app
  kubectl get pods -n jakal                                # List pods
  kubectl get svc -n jakal                                 # Get services
  kubectl logs -f deployment/jakal-backend -n jakal        # View logs
  kubectl port-forward svc/jakal-backend 8000:8000 -n jakal # Local access
  kubectl scale deployment jakal-backend --replicas=5     # Scale up

TESTING COMMANDS:
  curl http://localhost:8000/api/health                   # Health check
  curl http://localhost:8000/api/dashboard/fleet          # Get fleet data
  docker compose exec backend pytest tests/ -v             # Run all tests
  docker compose stats                                     # View metrics

DOCKER HUB COMMANDS:
  docker login                                             # Login to Docker Hub
  docker build -t yourname/jakal-backend:3.0.0 .         # Build image
  docker push yourname/jakal-backend:3.0.0               # Push to registry
  docker pull yourname/jakal-backend:latest               # Pull image

🆘 IF SOMETHING GOES WRONG
═══════════════════════════════════════════════════════════════════════════════

COMMON ISSUES & QUICK FIXES:

Problem: "Port 8000 already in use"
Solution: 
  - Edit docker-compose.yml
  - Change "8000:8000" to "8001:8000"
  - Use http://localhost:8001 instead

Problem: Docker container exits immediately
Solution:
  - Run: docker compose logs backend
  - Read the error message
  - Most common: Missing environment variables (check .env file)

Problem: "Cannot access external IP" (cloud deployment)
Solution:
  - Wait 2-3 minutes (load balancer provisioning)
  - Run: kubectl get svc -n jakal
  - Look for EXTERNAL-IP column
  - Refresh page if it was previously unavailable

Problem: "Out of disk space"
Solution:
  - Run: docker system prune -a --volumes
  - This removes old images and volumes
  - Reclaims 10-50 GB of disk space

Problem: "Connection refused" when accessing dashboard
Solution:
  - Check containers are running: docker compose ps
  - Check port mapping: docker port
  - Check logs: docker compose logs backend
  - Try different port: http://localhost:8001

FULL TROUBLESHOOTING:
  See: DEPLOYMENT_CHECKLIST.md → Troubleshooting section
